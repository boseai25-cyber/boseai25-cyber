## 🎮 Game Development

### 🗡️ [The Last King](https://github.com/boseai25-cyber/godot-last-king) — Godot 4, 3D strategy-action

A 3D strategy-action game that mixes turn-based chess tactics with a survival-horror twist: you play a lone White King with a shotgun and a spear, fighting across a 16×16 ruined board while a "Willpower" resource drains and hallucinations intensify the lower it gets.

**Verified from the repo:**
- Built in **Godot 4**, written in **GDScript**
- Full chess movement rules, turn-based system with simple enemy AI
- Dual weapon system (shotgun / spear) tied to a willpower resource
- A 4-phase hallucination system that escalates as willpower drops
- Check / checkmate detection plus a "Last Stand" comeback mechanic
- Save/load system
- 42 commits, modular manager-based architecture (game, turn, piece, audio, VFX managers)
- Documented status: core gameplay loop is complete and functional; art/audio assets and shader polish are still in progress

🔗 [View Repository](https://github.com/boseai25-cyber/godot-last-king)
